## Risks

| # | Risk | Mitigation |
|---|---|---|
| R1 | Formula/function coverage gaps | `Opaque` → judge + data, never a silent pass; coverage tracked in the eval |
| R2 | LLM false positives erode trust | Rule-first; data decides disagreements; eval precision gate |
| R3 | Data validation cost on large tables | Aggregate-first probes, date windows, caching, WLM query group |
| R4 | Matching data ≠ matching logic | `latent_policy`; static findings kept alongside the data verdict |

look & feel · automatic fixes · Strategy performance tuning.
