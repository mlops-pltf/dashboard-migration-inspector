| Tier | Environment variable | Used for |
|---|---|---|
| `strong` | `INSPECTOR_LLM_MODEL_STRONG` | The Inspector and expert agents: investigation, formula and SQL meaning, review |
| `fast` | `INSPECTOR_LLM_MODEL_FAST` | The data agent's conversation; cheap interpretation |

The value is a LiteLLM model id. `INSPECTOR_LLM_API_BASE` overrides the endpoint (an Ollama server); credentials
come from the provider's usual environment.

<Tabs>
	<TabItem label="Ollama (local default)">
		```bash title=".env"
		INSPECTOR_LLM_MODEL_STRONG=ollama_chat/qwen3:14b
		INSPECTOR_LLM_MODEL_FAST=ollama_chat/qwen3:8b
		INSPECTOR_LLM_API_BASE=http://host.docker.internal:11434   # Ollama on the Mac, seen from containers
		```
		Use `http://ollama:11434` with `--profile local-llm`, or the URL of a RunPod Ollama server.
	</TabItem>
	<TabItem label="Anthropic API">
		```bash title=".env"
		INSPECTOR_LLM_MODEL_STRONG=anthropic/claude-sonnet-5-5
		INSPECTOR_LLM_MODEL_FAST=anthropic/claude-haiku-5-5
		ANTHROPIC_API_KEY=...
		```
	</TabItem>
	<TabItem label="Bedrock (client / AgentCore)">
		```bash title="runtime environment"
		INSPECTOR_LLM_MODEL_STRONG=bedrock/<model or inference profile id>
		INSPECTOR_LLM_MODEL_FAST=bedrock/<model or inference profile id>
		AWS_REGION=...
		```
		Each AgentCore runtime calls Bedrock with its own IAM role: no keys, no proxy to run or secure.
	</TabItem>
</Tabs>

## Switching provider

<Steps>
1. Set `INSPECTOR_LLM_MODEL_STRONG` / `INSPECTOR_LLM_MODEL_FAST` (and the provider's endpoint or key) in `.env`.
2. `docker compose up -d` recreates the agents with the new environment.
3. Agent code keeps calling `llm.get_model("strong")` / `get_model("fast")`.
</Steps>

## Repeatable results

- Temperature 0, and every prompt is **versioned** (`prompts/system.md` in each agent).
- What the LLM concludes is checked by the evidence ledger: a pass needs a proof, and the verdict is computed.

<Aside type="caution" title="Claude Pro subscriptions">
	A Pro subscription doesn't include API access, so local runs use Ollama or an Anthropic API key. Ollama is
	fine for testing the plumbing but is noticeably weaker at equivalence judgments.
</Aside>
