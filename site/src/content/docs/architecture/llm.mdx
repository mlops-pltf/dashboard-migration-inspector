## Switching provider

<Steps>
1. Set `LITELLM_PROFILE=anthropic` or `ollama` in `.env`.
2. `docker compose up -d litellm` (add `--profile local-llm` to also start Ollama).
3. Agents keep calling `inspector-strong` / `inspector-fast` through each agent's `llm.get_model()`.
</Steps>

## Repeatable results

- Temperature 0, and every prompt is **versioned**.
- Judge outputs are **cached** by `sha256(canonical inputs + prompt version + model alias)`. Re-running after an unrelated fix doesn't re-judge, and repeated runs give the same verdict.
- Judges get **minimal, structured context**: resolved definitions and the relevant knowledge entries, never whole files.

<Aside type="caution" title="Claude Pro subscriptions">
	A Pro subscription doesn't include API access, so local runs use an Anthropic API key or Ollama.
	Ollama is fine for testing the plumbing but is noticeably weaker at equivalence judgments.
</Aside>
