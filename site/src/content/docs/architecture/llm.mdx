| Tier | Environment variable | Used for |
|---|---|---|
| `strong` | `INSPECTOR_LLM_MODEL_STRONG` | The Inspector and expert agents: investigation, formula and SQL meaning, review |
| `fast` | `INSPECTOR_LLM_MODEL_FAST` | The data agent's conversation; cheap interpretation (defaults to the strong model) |

The value is the provider's own model id. With `INSPECTOR_LLM_API_BASE` (and `INSPECTOR_LLM_API_KEY`) set, the agents
call that OpenAI-compatible server; without it they call Bedrock with the usual AWS credentials and `AWS_REGION`.
A host framework can also pass any Strands model object directly, e.g. `run_validation(package, model=...)`.

<Tabs>
	<TabItem label="RunPod (vLLM, local testing)">
		```bash title="terminal"
		export RUNPOD_API_KEY=...
		uv run infra/runpod/llm_pod.py up      # one GPU pod, vLLM with tool calling; prints the .env lines
		uv run infra/runpod/llm_pod.py stop    # or `down`: a running pod bills per hour
		```
		```bash title=".env"
		INSPECTOR_LLM_MODEL_STRONG=Qwen/Qwen3-32B-AWQ
		INSPECTOR_LLM_MODEL_FAST=Qwen/Qwen3-32B-AWQ
		INSPECTOR_LLM_API_BASE=https://<pod id>-8000.proxy.runpod.net/v1
		INSPECTOR_LLM_API_KEY=<generated by the script>
		```
		The proxy URL is public, so the server requires the generated key. Standalone: the agents never import it.
	</TabItem>
	<TabItem label="Bedrock (project)">
		```bash title="runtime environment"
		INSPECTOR_LLM_MODEL_STRONG=<Bedrock model or inference profile id>
		INSPECTOR_LLM_MODEL_FAST=<Bedrock model or inference profile id>
		AWS_REGION=...
		# INSPECTOR_LLM_API_BASE unset
		```
		Each runtime calls Bedrock with its own IAM role: no keys, no proxy to run or secure.
	</TabItem>
</Tabs>

## Switching provider

<Steps>
1. Set `INSPECTOR_LLM_MODEL_STRONG` / `INSPECTOR_LLM_MODEL_FAST`, and `INSPECTOR_LLM_API_BASE` / `_KEY` for RunPod, in `.env`.
2. `docker compose up -d` recreates the agents with the new environment.
3. Agent code keeps calling `llm.get_model("strong")` / `get_model("fast")`.
</Steps>

## Repeatable results

- Temperature 0, and every prompt is **versioned** (`prompts/system.md` in each agent).
- What the LLM concludes is checked by the evidence ledger: a pass needs a proof, and the verdict is computed.
