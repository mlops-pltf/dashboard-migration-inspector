<Aside type="caution" title="Severity rule">
	**Anything that can change a number is a blocker.** Uncertainty is a **warning**. Cosmetic
	differences are **low**.
</Aside>

| Severity | Meaning |
|---|---|
| <Badge text="Blocker" variant="danger" /> | Can change a number. The package is not READY while one is failing or unverified. |
| <Badge text="Warning" variant="caution" /> | Might change results, or couldn't be confirmed yet. |
| <Badge text="Low" variant="note" /> | Visual only. Fix any time. |
| <Badge text="Info" variant="default" /> | Shown for context, e.g. extra Strategy fields. |

<Aside type="tip" title="Root causes, not noise">
	One wrong join can fail twenty KPIs. The report groups those under the **root cause** finding and
	lists the symptoms beneath it, so the developer fixes one thing.
</Aside>
