Some questions have no answer in the definitions. *Is this key unique?* depends on the data. *Do these two
different-looking formulas return the same numbers?* is easiest to answer by running both. For those, the
Inspector asks the **data agent**, the only agent with (read-only) access to Redshift.

## How the SQL is written

The **query compiler** turns *"this measure, by these dimensions, with these filters"* into SQL from either
side's IR, following that tool's semantics: joins taken from the measure's own table, joins applied only when
needed (or always, for Freeform SQL), aggregation levels, model filters, division by zero as NULL.

To make sure it computes what ThoughtSpot computes, it was checked against ThoughtSpot's own generated SQL:
**128 visualizations return identical numbers**.

Both sides' results are compared **inside the warehouse** (a full outer join on the dimensions, with a
tolerance), so only counts, totals and the largest differences come back, whatever the data size.

## How a measurement settles a lead

| Lead was | The data says | Result |
|---|---|---|
| UNVERIFIED | no difference / key unique / no rows affected | **PASS**, decided by rule + data |
| UNVERIFIED | difference / key not unique | **FAIL**, decided by rule + data |
| UNVERIFIED | can't decide (nothing to compile, depends on an unknown join type) | stays **UNVERIFIED**, with what was seen |
| FAIL | no impact on today's data | stays **FAIL**, marked **latent** |
| FAIL | impact | stays **FAIL**, with its size |

A measurement that could not run never counts as a pass.

## Safety

| | |
|---|---|
| Access | Read-only database user; the session itself is read-only and has a statement timeout |
| SQL guard | Exactly one `SELECT`; no DDL, DML, `COPY`, `UNLOAD`; dangerous functions denied; only allowed schemas |
| Results | At most 1,000 rows, samples only; aggregation happens in SQL |
| Credentials | Only the data agent has them (Secrets Manager on AgentCore) |

<Aside type="note">
	Data checks run in code **before** the AI starts. The AI can request more of them during its investigation;
	they go through the same compiler, guard and rules.
</Aside>
