## Design principles

<CardGrid>
	<Card title="Compare what is computed" icon="magnifier">
		Every field and KPI is traced down to Redshift columns, joins, filters and aggregation. A
		restructured model, even a single Freeform SQL source, can be compared with the ThoughtSpot
		original.
	</Card>
	<Card title="No pass without proof" icon="approve-check">
		A check that could change a number only passes when the definitions are proven identical or
		both sides return the same data. An LLM's opinion alone never passes a check.
	</Card>
	<Card title="Agent drives, tools prove" icon="setting">
		A Strands agent plans and reasons; exact tools read, trace, compare and analyse. Every tool result
		is evidence, and the ledger decides what a finding may claim.
	</Card>
	<Card title="Data breaks the tie" icon="random">
		When the definitions can't be compared directly, both sides run against the same Redshift
		warehouse and the numbers decide, with a diagnosis when they differ.
	</Card>
</CardGrid>
