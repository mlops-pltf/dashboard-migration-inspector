Each expert is an independent package and A2A server with its own tools, prompt and container. It knows
**one** technology deeply and never judges the other side of a migration.

## Talking to an expert directly

Developers and reviewers can ask an expert about their export, e.g. *"In package S04, which tables does the
Freeform SQL join, and is any of them one-to-many?"*. Conversations continue by context id.
